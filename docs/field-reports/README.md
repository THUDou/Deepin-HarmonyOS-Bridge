# 真机验证报告

把每次设备矩阵验证记录为 `YYYY-MM-DD-<device>.md`，包含：

| 字段 | 示例 |
|---|---|
| 设备 | KaihongOS x86 / RK3588 / HarmonyOS NEXT 真机 |
| OS 版本 | KaihongOS 5.0.2.01 / HarmonyOS 5.0.0 |
| 桌面 | Deepin 25.2.2, Treeland (Wayland) / X11 |
| DHB 版本 | v0.1.0-alpha, commit |
| 网络 | Wi-Fi 6 5GHz / 以太网 / 手机热点 |
| 结果 | 发现 / PIN / Session / Bytes / 文件 / 屏幕 |
| 日志 | 脱敏后的 `hilog`/Klink/dhb 日志 |
| 问题 | 错误码、复现步骤、抓包 |

请勿包含：真实姓名、手机号、账号、未脱敏的 IP/MAC、文件内容。
